# Praaline

Praaline is an open-source system for spoken corpus management, annotation, visualisation, querying and analysis.

The **Silence Detector** plugin is available in Annotation > Automatic Annotation. It detects pauses in selected corpus recordings, writes phrase boundaries to the associated Transcriber (`.trs`) file and corpus annotation datastore, and labels each detected pause with `#`. Each run starts a fresh Transcriber annotation for the selected communication, replacing its previous `.trs` contents and Transcriber tiers so revised silence settings produce a clean result. The detector estimates a threshold from each recording's noise floor, applies hysteresis, and bridges brief energy spikes to avoid fragmented pauses; the configured threshold is its upper limit. The minimum pause duration defaults to 0.3 seconds. Transcriber tiers are matched to the communication's corpus speakers; if no speaker can be determined, assign one in Corpus Explorer rather than creating a placeholder. Open the communication in Transcriber to enter text into the resulting phrase intervals or in Visualisation/Correction to view and correct them.

Transcriber displays phrase boundaries over the acoustic waveform. Saved `.trs` files use the Transcriber 2 XML structure and `trans-13.dtd`, including speaker metadata and standard turn attributes. The canonical file is `communicationID.trs`; when only a file linked by corpus metadata exists, it is copied there and that communication's corpus annotation entries are redirected to the canonical file. Silence Detector reuses one `Transcriber` annotation entry per communication and cleans up duplicate entries created by earlier versions. Other `.trs` files in the folder are preserved because they may belong to different communications.

In Timeline Visualisation, **Save annotations** writes TRS edits to both the corpus annotation datastore and its associated `.trs` file. For TextGrid annotations, it likewise updates the linked Praat TextGrid file and replaces the stored tiers. In the annotation pane, use **Edit** (shortcut `3`) and drag an internal boundary to move it, or use **Erase** (shortcut `5`) and click an internal boundary to merge its adjacent intervals; the outer time limits cannot be removed. Moving a selected boundary with the left/right controls displays a red dashed marker at its new time across the visualisation panes. **Save all modified annotations** saves every annotation set edited during the current Praaline session, including edits from communications already left; unsaved edits are retained if you revisit a communication before saving. Reopening a saved annotation reloads its file and refreshes the datastore, so edits remain consistent after Praaline is closed and restarted. TextGrid tier names exported for multiple speakers retain the speaker association when reloaded. If a valid TextGrid contains no tiers, Praaline creates an empty `transcription` tier spanning the recording for each associated speaker so annotation can begin. If there is no speaker participation, TextGrid tiers are still loaded into an editing-only speaker group (using the filename stem when needed), without adding a speaker to the corpus; existing TextGrid levels are made visible automatically. **Save TRS** can identify a loaded Transcriber tier even when the corpus annotation metadata does not yet label its format as `trs`.

In **Annotation > Transcriber**, **Export TextGrid...** exports the annotation currently open in the annotation pane to a Praat TextGrid file. For multiple speakers, exported tier names include each speaker ID.

For an empty TextGrid, add a level in **Levels and Attributes**, enter its name (for example, `phonème`), leave **Attribute** empty to edit interval text, make sure **Show** is checked, then click **Update editor**. Praaline creates an editable interval tier for each speaker. Alternatively, add a row with **Level** set to `TextGrid` and **Attribute** set to the desired tier name (for example, `Phoneme` or `Syllable`); each such row is added as a real interval tier to the open TextGrid. Fill the tiers in the timeline and save with **Save annotations** or **Save TextGrid**. Both save actions write the TextGrid file; when a TextGrid is paired with a Transcriber annotation, Praaline reloads its tiers from that file when opening the pair so file-only tiers remain visible. When a selection is split with **A**, its start and end boundaries are added to each selected level and copied directly by time to interval tiers in the paired TextGrid for the same speaker, independently of label text; the existing label stays in the selected subinterval between those boundaries. The temporary selection markers disappear after the split, so they are not confused with saved tier boundaries. Transcriber boundaries are also synchronized by time when saving a paired TextGrid. In the annotation pane, select a range and press **A** to split the selected speaker's current interval at the range boundaries; the new intervals appear in Annotation Editor and can be removed with the eraser. The **TextGrid file** field in Correction tracking displays the destination file for all levels (hover over it to see the full path). If the **TextGrid corrector** field is blank, **Save TextGrid** asks for the corrector's name, as **Save TRS** does. The save actions also synchronize configured TextGrid tiers before writing the file.

The **Montreal Forced Aligner** plugin is available in Annotation > Automatic Annotation. It aligns non-empty intervals from an existing Transcriber tier with the recording, using short audio segments per speaker, and imports the resulting word (`token`) and phoneme (`phone`) tiers into the corpus annotation datastore. MFA TextGrid output is read as UTF-8 so IPA characters are preserved. When a Transcriber annotation is opened, Praaline merges these datastore tiers with the tiers reloaded from the TRS file and adds them to the timeline editor; they are not written into the TRS file. Use **Save TextGrid** in Timeline Visualisation to save the open tiers as a Praat TextGrid; if the communication has no TextGrid annotation yet, Praaline creates one and adds it to the corpus. Alternatively, export selected levels with **Corpus > Export annotations...**. Install MFA separately with Conda as described in the [MFA getting-started guide](https://montreal-forced-aligner.readthedocs.io/en/latest/getting_started.html), then install compatible acoustic and dictionary models. Configure the plugin with the MFA executable and installed model names (for example `french_mfa`); `mfa model list acoustic` and `mfa model list dictionary` list available models. The plugin uses MFA's legacy acoustic-model alignment workflow (called `align_legacy` in MFA 4). MFA aligns existing text; it does not generate a transcript.

## Portable macOS package

On Apple Silicon, run `python3 app/package-macos.py` after building Praaline to create `dist/Praaline-macOS-arm64.zip`. Extract the ZIP and keep `Praaline.app` beside the `plugins` folder; launch the app from Finder. The package includes Qt and the native libraries needed by Praaline, but it is not built for Intel Macs. Montreal Forced Aligner and its models must still be installed separately. The app is ad-hoc signed, not notarized, so macOS may require confirmation on first launch.

See [INSTALLATION.md](./INSTALLATION.md) for the current macOS package, MFA setup, and Windows build availability.
