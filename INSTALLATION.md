# Installer Praaline sur macOS et Windows

## macOS (Apple Silicon)

Le dossier `Praaline-0.9.10-source` contient le code source, pas le paquet macOS prêt à installer. Il ne contient donc pas le dossier `dist/` ni l’archive `Praaline-macOS-arm64-2026-11-02.zip`.

Pour distribuer Praaline sur un Mac Apple Silicon, il faut obtenir séparément un paquet macOS compilé ou le construire depuis ces sources avec les dépendances et Qt appropriés. Une fois le paquet obtenu, gardez le dossier `plugins` à côté de `Praaline.app` et ne déplacez pas l’application hors de ce dossier.

Au premier lancement, macOS peut demander une confirmation. Si nécessaire, faites un clic droit sur l’application, choisissez **Ouvrir**, puis confirmez.

Un paquet macOS correctement construit contient Praaline, Qt et les plugins compilés pour Apple Silicon. Il n’inclut pas Montreal Forced Aligner (MFA), qui doit être installé séparément. Pour l’environnement MFA utilisé lors de la validation de cette version :

1. Installez MFA et les modèles acoustique et dictionnaire `french_mfa` dans un environnement Conda.
2. Dans **Annotation > Automatic Annotation**, cochez **Montreal Forced Aligner**.
3. Dans **MFA executable**, indiquez le chemin de l’exécutable MFA de cet environnement, par exemple `/Users/votre-nom/anaconda3/envs/praaline-mfa/bin/mfa`.
4. Réglez **Language / acoustic model** et **Pronunciation dictionary** sur `french_mfa`.

Praaline enregistre automatiquement ce chemin dans ses préférences dès qu’il est modifié.

Le chemin dépend de l’emplacement de Conda sur votre Mac. Les Mac Intel ne sont pas pris en charge par ce paquet Apple Silicon.

## Compiler les sources sur ce Mac (Apple Silicon)

Depuis Terminal, à la racine du dossier source, régénérez les fichiers de compilation puis compilez Praaline :

```sh
cd /Users/nj/Downloads/Praaline-0.9.10-source
/opt/homebrew/opt/qt@5/bin/qmake Praaline.pro CONFIG+=release
make -j4
```

Le projet nécessite Qt 5 et ses modules utilisés par Praaline, ainsi que les outils de compilation Xcode Command Line Tools. Après une compilation réussie, lancez l’application avec :

```sh
open app/build/Praaline.app
```

Si le dossier source contient des fichiers `Makefile` générés à un autre emplacement, supprimez-les avant de compiler. Depuis la racine du dossier :

```sh
find . -type f -name 'Makefile*' -exec grep -l '^# Generated by qmake' {} + | while IFS= read -r file; do rm "$file"; done
rm -f .qmake.stash
/opt/homebrew/opt/qt@5/bin/qmake Praaline.pro CONFIG+=release
make -j4
```

Les fichiers de compilation qmake contiennent le chemin local du projet ; il faut les régénérer après avoir déplacé le dossier source.

## Windows (PC)

### Installer Qt pour compiler Praaline

Qt n’est nécessaire que pour **compiler** Praaline. Pour la chaîne Windows testée avec ces sources, installez **Qt 5.15.2** et **MinGW 8.1.0 en 32 bits (x86)**. Une autre version de Qt ou une installation 64 bits n’est pas interchangeable avec les bibliothèques et dépendances compilées pour cette chaîne.

1. Téléchargez l’[installateur Qt officiel](https://www.qt.io/download-qt-installer) et lancez-le. Connectez-vous ou créez un compte Qt si l’installateur le demande.
2. Dans la sélection des composants, choisissez **Qt 5.15.2 > MinGW 8.1.0 32-bit** et l’outil **MinGW 8.1.0 32-bit** dans **Developer and Designer Tools**. Qt Creator est facultatif.
3. Si Qt 5.15.2 n’apparaît pas dans la liste des versions proposées, consultez les [archives de Qt](https://download.qt.io/archive/qt/) et les options proposées par l’installateur pour les anciennes versions. L’accès aux versions archivées peut dépendre de votre compte et de la licence Qt.
4. Après l’installation, vérifiez que `qmake.exe` et le compilateur `g++.exe` sont présents. Par exemple, avec une installation dans `C:\Qt`, ils se trouvent respectivement dans `C:\Qt\5.15.2\mingw81_32\bin` et `C:\Qt\Tools\mingw810_32\bin`. Si vous choisissez un autre dossier, adaptez ces chemins et ajoutez les deux répertoires au `PATH` avant de lancer qmake et la compilation.

L’exécutable Windows a été compilé et lancé avec Qt 5.15.2 et MinGW 8.1.0 32 bits. Pour **exécuter** une distribution complète, il n’est pas nécessaire d’installer le SDK Qt : elle doit toutefois inclure les DLL Qt et MinGW, les DLL tierces requises ainsi que les plugins nécessaires (notamment `plugins\platforms\qwindows.dll`). Le lancement a été vérifié sur la machine de compilation ; une archive autonome testée sur un autre PC n’est pas encore fournie. L’ancienne archive Win32 de Praaline 0.9.10, [publiée en 2018](https://github.com/praaline/Praaline/releases/download/v0.9.10/Praaline-0.9.10-win32.zip), ne contient pas le dossier de plugins et n’inclut pas les améliorations MFA de ce dépôt.

## Montreal Forced Aligner

MFA et ses modèles sont des composants externes et ne sont inclus dans aucun paquet Praaline. Les messages d’erreur de MFA apparaissent dans le panneau de sortie de l’annotation automatique. Pour créer un TextGrid après l’alignement, ouvrez la communication dans **Visualisation/Correction**, puis utilisez **Save TextGrid**.
